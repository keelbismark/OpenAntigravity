# Roadmap

> Статус: **v1.6.0** — все пункты предыдущего роадмапа закрыты или сведены
> к наблюдаемым остаткам. Правило файла — **Evidence Before Assertions**:
> каждый пункт от измеренного симптома. История — [docs/POSTMORTEM.md](docs/POSTMORTEM.md).

## Закрыто в v1.6.0

| Пункт | Что сделано | Проверка |
|---|---|---|
| Диагностика одним вопросом | `--relay-status`: сборки, владелец роли, дверь, прокси, гейт-хосты, первый маршрут, блокировки | 2 теста текста |
| `WSAEACCES` при bind | при отказе проверяется `netsh http show urlacl`; если резервации нет — явно сказано, что остаются WFP / эксклюзивная привязка / динамический порт | тест парсера urlacl |
| Залипание тёплого прохода | каждый шаг ставит `WARM_STEP`; guard пишет имя шага перед завершением процесса | тест «у всех шагов есть имя» |
| Дверь переживает релей | watchdog (отдельная задача) держит `127.65.71.1/2:443` и публикует `door.json`; релей читает метку и уступает bind; принятые соединения повторяют туннель до 30 с | тест свежести метки |
| In-process путь основным | при реальном изменении `OAG_GATEWAY` перезапускается только `language_server`; IDE поднимает его заново уже с переменной; редактор не трогается | тест списка целей |
| Portable-переработка | подтверждено пробным прогоном: `portable.flag` удерживает portable-режим, `data\` не удаляется, watchdog применяет патч `extension.js`, `signature gone … main.js` — ожидаемое поведение | полевой прогон v1.5.9 |

## Остаточные вопросы (не блокеры)

- **Источник `WSAEACCES` 10013** точно не установлен — теперь отчёт называет все
  проверки и оставшихся подозреваемых, но сам WFP/эксклюзивную привязку мы не
  измерили. Гипотеза про bound-but-not-listening сокет **опровергнута замером**,
  правка откачена — не повторять.
- **Причина залипания `warm_forever`** не установлена — но теперь она будет
  названа в логе, если повторится.
- **Производительность в полевых условиях** — дверь в watchdog и 30-секундное
  ожидание туннеля не проходили нагрузочный тест «20 перезапусков»; это
  следующий шаг, если появятся жалобы.

## Воспроизведение ключевых замеров

```
# 10061 только при отсутствии слушателя
bind 127.65.71.9:443; connect → 10061

# отравленная запись о порте
proxy_port = 44129 при живом 53129, OAG_GATEWAY выставлен, 110 с → жив

# роль
два --relay-role → второй busy; после убийства первого роль свободна

# кросс-процессная дверь
свежий door.json → релей продолжает подменять адреса без своего слушателя

# расхождение версий и источник настроек — строки в --relay-status и отчёте
```
